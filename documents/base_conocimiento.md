# Base de Conocimiento Central - Academia de Tecnología e IA

## 1. Oferta Académica y Programas de Formación

### Curso 1: Desarrollo de Bots con Telegram e IA
* **Duración:** 4 semanas (20 horas lectivas | 5 hrs/semana).
* **Modalidad:** 100% online en vivo vía Zoom con acceso ilimitado a grabaciones en HD.
* **Nivel:** Intermedio.
* **Prerrequisitos:** Conocimientos básicos de Python (variables, funciones, listas, diccionarios y control de flujo).
* **Perfil de Egreso:** El egresado será capaz de diseñar, programar, integrar con modelos de lenguaje (LLM) y desplegar bots automatizados listos para producción.
* **Temario Detallado:**
  * **Módulo 1: Fundamentos de la API de Telegram**
    * Creación y gestión de bots con @BotFather.
    * Configuración de webhooks vs. Polling.
    * Manejo seguro de API Keys y tokens.
  * **Módulo 2: Entornos de Desarrollo y Arquitectura Asíncrona**
    * Creación de entornos virtuales (`venv`, `poetry`).
    * Manejo de variables de entorno (`.env`).
    * Programación asíncrona en Python con `asyncio` y la librería `python-telegram-bot`.
  * **Módulo 3: Integración con Modelos de Inteligencia Artificial**
    * Conexión con la API de Google Gemini mediante LangChain.
    * Prompt engineering aplicado a respuestas estructuradas.
    * Gestión de memoria y contexto de conversación por usuario.
  * **Módulo 4: Arquitecturas RAG (Retrieval-Augmented Generation)**
    * Conceptos de embeddings y bases de datos vectoriales (ChromaDB / FAISS).
    * Indexación y procesamiento de documentos locales (PDF, TXT, CSV).
    * Consulta inteligente de información corporativa desde Telegram.
  * **Módulo 5: Despliegue y Mantenimiento en Producción**
    * Configuración de servidores VPS (Linux / Ubuntu Server).
    * Creación de servicios del sistema con `systemd` para ejecución 24/7.
    * Monitoreo de errores, logging y estrategias de autoreinicio.

### Curso 2: Python para Ciencia de Datos e Inteligencia Artificial
* **Duración:** 8 semanas (40 horas lectivas | 5 hrs/semana).
* **Modalidad:** Online asincrónico (videoclases HD en plataforma LMS + tutorías semanales en vivo).
* **Nivel:** Principiante / Desde cero.
* **Prerrequisitos:** Ninguno.
* **Perfil de Egreso:** El estudiante adquirirá la capacidad de manipular grandes volúmenes de datos, realizar análisis exploratorio avanzado y construir modelos predictivos de Machine Learning.
* **Temario Detallado:**
  * **Módulo 1: Fundamentos de Programación en Python 3.12**
    * Sintaxis, tipos de datos y estructuras avanzadas.
    * Programación orientada a objetos (POO) básica.
    * Manejo de excepciones y lectura/escritura de archivos.
  * **Módulo 2: Procesamiento de Datos con Pandas y NumPy**
    * Operaciones matriciales y arreglos multidimensionales con NumPy.
    * Limpieza, filtrado, imputación de nulos y transformación de DataFrames con Pandas.
    * Agrupaciones (`groupby`), fusiones (`merge`/`join`) y tablas pivote.
  * **Módulo 3: Análisis Exploratorio de Datos (EDA) y Visualización**
    * Gráficos estadísticos con Matplotlib y Seaborn.
    * Identificación de patrones, correlaciones y valores atípicos (*outliers*).
    * Creación de tableros visuales interactivos.
  * **Módulo 4: Machine Learning con Scikit-Learn**
    * Conceptos de aprendizaje supervisado vs. no supervisado.
    * Algoritmos de Clasificación (Logística, Árboles de Decisión, Random Forest).
    * Algoritmos de Regresión (Lineal, Polinomial).
    * Métricas de evaluación (Matriz de confusión, ROC-AUC, RMSE, $R^2$).
  * **Módulo 5: Pipelines y Despliegue de Modelos**
    * Creación de pipelines de procesamiento de datos.
    * Serialización de modelos con `joblib` / `pickle`.
    * Introducción a la exposición de modelos mediante APIs REST (FastAPI).

### Curso 3: Prompt Engineering y Agentes de IA
* **Duración:** 4 semanas (20 horas lectivas | 5 hrs/semana).
* **Modalidad:** 100% online en vivo con laboratorios prácticos.
* **Nivel:** Principiante a Intermedio.
* **Prerrequisitos:** Uso básico de herramientas digitales.
* **Perfil de Egreso:** Diseñar arquitecturas de prompts complejas y construir sistemas de agentes autónomos para automatización de tareas.
* **Temario Detallado:**
  * **Módulo 1:** Tácticas avanzadas de prompting (Few-shot, Chain-of-Thought, ReAct).
  * **Módulo 2:** Estructuración de datos de salida (JSON, Markdown, YAML) para integraciones.
  * **Módulo 3:** Diseño de agentes autónomos con CrewAI y LangGraph.
  * **Módulo 4:** Automatización de flujos de trabajo e integración de herramientas externas (APIs, búsqueda web).
