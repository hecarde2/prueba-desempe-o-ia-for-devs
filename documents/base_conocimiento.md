# Base de Conocimiento - Academia de Tecnología e IA

## 1. Oferta Académica y Cursos

### Curso 1: Desarrollo de Bots con Telegram e IA
* **Duración:** 4 semanas (20 horas lectivas).
* **Modalidad:** 100% online en vivo con acceso a grabaciones.
* **Prerrequisitos:** Conocimientos básicos de Python (variables, funciones y estructuras de control).
* **Temario:**
  * Introducción a la API de Telegram y BotFather.
  * Configuración de entornos virtuales y manejo de variables de entorno (`.env`).
  * Integración con modelos LLM de Google Gemini mediante LangChain.
  * Implementación de arquitecturas RAG para consulta de documentos locales.
  * Despliegue del bot en servidores VPS (Linux/Ubuntu).

### Curso 2: Python para Ciencia de Datos e Inteligencia Artificial
* **Duración:** 8 semanas (40 horas lectivas).
* **Modalidad:** Online asincrónico con tutorías semanales.
* **Prerrequisitos:** Ninguno.
* **Temario:**
  * Fundamentos de programación en Python 3.12.
  * Manipulación de datos con Pandas y NumPy.
  * Visualización de datos con Matplotlib y Seaborn.
  * Algoritmos de Machine Learning con Scikit-Learn.
  * Creación de pipelines de datos y análisis exploratorio (EDA).
